# LogBro Docs

Public documentation for **LogBro**, a fast, private note-taking app for iOS.

Organise notes into categories, write with a simple block editor (text,
bullets, checkboxes, and photos), tag and search everything, and keep it all in
sync across your devices with iCloud. Share a category with family or teammates
to work on the same notes together.
