# ScanBro Docs

Public documentation for **ScanBro**, a quick box-logging app for iPhone and
iPad.

Tap **Incoming** or **Outgoing**, point the camera at the QR code or barcode on
a box, and the scan is saved straight to a CSV file. When a label has several
codes you choose the right one, and you can add a note to any scan from the log.
Export the file whenever you need it. Everything stays on your device.
