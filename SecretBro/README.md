# SecretBro Docs

Public documentation for **SecretBro**, a private password, pincode, and secrets
manager for iPhone.

Save logins, cards, bank details, Wi-Fi, passports and notes behind Face ID —
each category shows the fields that fit it. Generate strong passwords, import
from CSV or 1Password (.1pif), and let iOS fill your passwords for you with the
built-in AutoFill extension. Everything you store is encrypted on device and
synced across your own devices with iCloud — SecretBro has no accounts and no
servers of its own.
